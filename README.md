# Microbial activity altered in captive octocorals
In this study, we used metatranscriptomics and 16S amplicon sequencing to compare the taxonomic composition and functional activity of the microbial communities associated with the mesophotic octocoral Swiftia exserta before and after one year in captivity.

## Description
The code, input and output files are provided for the analyses performed in this study. Additonal files larger than 100 Mb are availabel on DRYAD, https://doi.org/10.5061/dryad.4b8gthttt.

The raw sequence data is available on NCBI SRA repository, under Mesophotic and Deep Benthic Communities BioProject PRJNA1135238.
